## 🚀 Projects

### 🛡️ [Augmented Defense](https://github.com/SevenStardla/Augmented_Defense)

A 2D wave-defense game currently being developed in Unity.

The player moves around the battlefield, attacks enemies, and places towers to protect the core.  
After each wave, the player chooses an augment that improves towers, the defender, the economy, or the core.

#### Implemented Features

- Game-state-driven gameplay flow
- Path-based enemy movement and wave spawning
- Standard, runner, tank, and boss enemies
- Tower placement and automatic attacks
- Player movement and direct attacks
- Augment selection, stacking, and stat application
- Gold economy and core health systems
- Game speed controls
- Victory, defeat, and restart flow
- Unity UI and visual combat feedback
- WebGL build support

#### Tech

`Unity 6` `C#` `Unity UI` `2D Physics` `WebGL`

---

### ❄️ [FrostPeak Survival](https://github.com/SevenStardla/FrostPeak_Survival)

A 2D survival game built with Unity where the player must reach the goal before losing all body temperature.

The player’s temperature gradually decreases over time and can be restored by staying near a campfire.  
When the player reaches the goal, the game records and displays the total survival time.

#### Implemented Features

- Player movement and input handling
- Character animation
- Camera follow system
- Temperature depletion over time
- Temperature recovery near campfires
- Player death when temperature reaches zero
- Goal detection and survival-time tracking
- Main menu, gameplay, and result scene transitions
- Game restart and exit controls
- TextMeshPro UI and button sound effects

#### Tech

`Unity 6` `C#` `Unity UI` `TextMeshPro` `2D Physics`
